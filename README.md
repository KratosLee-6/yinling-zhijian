# 银龄指尖 👴📱

> 让爸妈跟上时代 —— 专为中老年人打造的手机软件使用指南

> 🚧 **教程内容仍在迭代优化中** —— 本仓库为可用的 H5 原型 + 内容生产线，教程图文会持续校准（最终以各 APP 官方界面为准）。**有需要的可直接 fork 自行迭代**：改 `data/` 下的数据文件即可增删教程，配套门禁与测试会帮你兜底（见下方「自行迭代指南」）。欢迎 PR。

## 项目简介

**银龄指尖** 是一个面向中老年用户（55-75岁）的数字服务产品，以**分步图解 + 语音播报 + 防骗查询**的方式，帮助中老年人学会使用日常刚需 APP。

产品三段式路线（详见 `_交付/01-PRD.md`）：

```
教着用（H5/小程序教程）→ 陪着用（家人协助）→ 替着用（安卓无障碍直达 APP）
```

当前版本：**V6.2**（H5 阶段，盒 1 交付物）

## 核心功能

- 📖 **61 条分步教程 / 244 步**：每步 ≤15 字，一步一屏，上一页/下一页跟做
- 🖼️ **每步配教学示意图**：244 步全量覆盖（红圈标注点哪里，`tools/make-diagrams.js` 生成，真机截图到位后可逐条替换）
- 📲 **真实界面画廊**：每个 APP 页顶部展示官方商店真机截图（48 张），先认界面再学操作
- 📕 **官方手册直达**：每个 APP / 品牌页底部可跳官方使用手册（15 个官方域名白名单）
- 📱 **分品牌手机设置**：华为/小米/OPPO/vivo/苹果/三星各 4 条（WiFi/清内存/蓝牙/系统更新），官方品牌图标
- 🔊 **语音播报**：每步可朗读（Web Speech API），支持自动朗读开关
- 🛡️ **防骗查一查**：23 条高发话术库（中奖/退款/冒充公检法/刷单/杀猪盘…），附「三问子女」与 96110 一键拨号
- 📢 **辟谣查一查**：31 条核查库（饮食养生/疾病医疗/食品安全/生活流言），危险级强制「问医生」，附官方辟谣平台链接
- ❤️ 收藏 · 🔍 搜索 · 🔤 字号三档（18/22/26px）

## 本地试用与测试

```bash
npm install            # 首次：安装测试依赖（acorn + jsdom）
npm run check          # 交付门禁：语法(acorn 纯解析) + 数据完整性 + 资源/承诺/白名单校验
npm test               # 自动化测试套件：55 项断言（jsdom，无需真实浏览器）
npm run serve          # 本地试用：http://127.0.0.1:8931/

# 内容生产线（改数据后按需重跑）
npm run diagrams       # 重新生成 244 步教学示意图 + 注册表
npm run shots          # 重新拉取商店真机截图 + 注册表
npm run shotlist       # 生成《M1-真机拍摄脚本》（61 条/244 步逐屏清单）
```

改完内容（data/ 下数据文件）后 **check + test 双绿再提交**；真机/浏览器手工验收用 serve。

## 改内容须知

1. **只改 `data/` 下的数据文件**（tutorials.js / rumors.js），不动 index.html / app.js
2. 步骤文案 ≤15 字（超长会被门禁拦截）；中文引用用「」，**禁用半角双引号**（v5 两次整页挂掉的根源）
3. 步骤配图自动按命名约定生效：`assets/steps/<教程id>-<步>.svg`（跑 `npm run diagrams` 生成）
4. 官方手册只能加白名单内官方域名（门禁强制）；改完跑 `npm run check && npm test`，双绿再提交

## 自行迭代指南

不需要读懂全部代码，三条路按需选：

| 你想做的 | 怎么做 | 兜底 |
|---|---|---|
| 增删改教程内容 | 只改 `data/tutorials.js`（步骤 ≤15 字、用「」不用半角引号），跑 `npm run diagrams` 重新生成配图 | 门禁自动校验字数/引号/图片存在性 |
| 替换某步配图为你的真机截图 | 把图放到 `assets/steps/<教程id>-<步>.png`（或 jpg），改 `data/step-imgs.js` 对应项指向新文件 | 门禁校验注册表与文件一致 |
| 校准防骗/辟谣话术 | 只改 `data/tutorials.js` 话术库 / `data/rumors.js` 核查库 | 危险级条目强制含「问医生/遵医嘱」 |

改完必跑：

```bash
npm run check && npm test   # 双绿再提交
npm run serve               # 本地人工过一遍
```

 fork 后自行维护无需告知我们；如果改得好，欢迎 PR 回来帮到更多老人。
